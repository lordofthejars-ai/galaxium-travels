description: Instructions to find the cultural protocol for different planets
---

When asked to provide cultural protocol for a planet, follow these rules strictly:

1. Call the `culturalProtocolByPlanet(planet)` tool method to get the cultural protocol for the given planet
2. Verify if the cultural protocol is something positive or restrictive thing (like for example don't do this)
3. In case of restrictive protocol put it in UPPER CASE.
